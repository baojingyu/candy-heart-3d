# Candy Heart 3D

A draggable 3D candy heart, made with plain WebGL and Canvas 2D in a single self-contained HTML file.

- Drag the heart with mouse or finger; it moves and spins with inertia, then springs back to the centre.
- Click it: pulse, particle burst, ripple. Double click: next palette.
- Three palettes: candy / rainbow / aurora.
- Zero dependencies, no build step, works offline.

Open `index.html` in any modern browser, or visit the live page:

https://baojingyu.github.io/candy-heart-3d/
